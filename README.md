**A work in progress**

## Project title

Coding Log

## Brief description

A CLI program written mostly in python that generates a daily log to record what one did that day in terms of coding work. It asks the user a series of questions about their coding activities that day and writes the answers to a markdown file at a path provided by the user.

See the [functionality overview](https://github.com/rhytidia/coding_log_python/wiki/Functionality-overview) page on the project wiki for more details.

## Motivation

As part of a learning path on [Boot.dev](https://boot.dev), we need to create a personal project. I know python best so decided to create something in python. Though I know one could easily just generate a template for a markdown note and fill it out whenever one wants, I wanted to do this for learning, and also to create something I could actually use.

## Status

Main functionality completed, working on unit testing (see [this project's functionality overview](https://github.com/rhytidia/coding_log_python/wiki/Functionality-overview)). More granular progress can be found on the [progress page](https://github.com/rhytidia/coding_log_python/wiki/Progress) for this project.

I had originally wanted to add a GUI to this program, but decided to just focus on learning more about unit testing with mock and testing most of the program's functionality that way. The GUI would add a lot more time and need for refactoring, and I'd like to call this one finished for now and possibly do more with it later (or not).
